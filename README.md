# Farm Worker Portfolio

Proyek sederhana untuk GitHub Pages. Cocok sebagai portofolio online atau profil kerja sederhana.

## Isi proyek
- `index.html` — halaman utama portofolio
- `style.css` — tampilan halaman
- `script.js` — tombol download/print resume
- `.gitignore` — file yang tidak perlu masuk GitHub

## Cara upload ke GitHub
1. Buat repository baru di GitHub, misalnya: `farm-worker-portfolio`
2. Upload semua file dari folder ini
3. Buka **Settings > Pages**
4. Pada **Source**, pilih branch `main`
5. Simpan, lalu tunggu sampai link GitHub Pages muncul

## Cara edit
Buka `index.html`, lalu ganti:
- Nama
- Lokasi
- Nomor WhatsApp/email
- Pengalaman kerja
- Keahlian
